ITW III Chat Project
A simple Python-based chat application that allows users to communicate over a network using sockets.
Features
- Real-time messaging using Python sockets.
- Client-server architecture.
- Graphical user interface using Tkinter.
Technologies Used
- Python
- Socket programming
- Tkinter
- Threading


How to Run
1. Download or clone the repository.
2. Open a terminal in the project folder.
3. Start the server:
open the terminal
python server.py


4. Open another terminal and start the client:
python client.py
